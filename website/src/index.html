08 Common questions

Clear answers
for a research build.

Scope is part of the product. Here is what Limulator needs and what its current evidence means.

Does this replace Xcode or the iOS Simulator?+

No. Limulator uses xtool and an Xcode SDK archive to build an iPhone app, then runs that app inside a locally emulated iOS guest. It is a Linux development and testing path with different tradeoffs from Apple's tools.

Is the Duo app workflow already proven?+

Debug and release CounterLab IPAs build with SDK 27.2. The iOS restore completed successfully; native boot, app install, launch, input, persistence and screenshots are still being validated.

Can I use any iPhone, iPad, or App Store app?+

Compatibility is profile-specific. The Duo profile has one visible cover framebuffer, an experimental software inner iOS display and software fold postures; native layout and touch behavior remain unverified. Firmware for iPhone 16 and iPad mini has been verified; those guests await runtime checks. Locally built ARM64 apps are the intended input; encrypted App Store executables are rejected.

Does a passing QEMU benchmark mean my app will run faster?+

No. The published measurement isolates one translated-code cache invalidation path. App boot, interaction, graphics and end-to-end latency have not been measured.

What does the public preview include?+

The source repository is public as a research preview. Native app execution and device profiles are still being validated; public source availability does not establish runtime compatibility.
